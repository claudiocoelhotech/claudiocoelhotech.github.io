# claudiocoelhotech.github.io

Site pessoal de Cláudio Coelho — Gerente de Projetos, Gestão de Contratos, Setor Público e Tecnologia.

Publicado com GitHub Pages em <https://claudiocoelhotech.github.io>.

## Estrutura

- `index.html` — página única, autossuficiente. Todo o CSS, o JavaScript e as imagens
  (logos dos órgãos atendidos, em base64) estão embutidos no próprio arquivo.
  A única dependência externa são as fontes Archivo e JetBrains Mono, do Google Fonts.

## Como publicar uma atualização

1. Edite o `index.html`.
2. `git add index.html && git commit -m "atualiza o site" && git push`.

O GitHub Pages republica sozinho em alguns segundos.
